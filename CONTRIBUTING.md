# Contributing to ICTERP

Thanks for helping. A few things make reviews quick:

- One change per pull request, with a short description of why.
- Add or update a test in the module's `tests/` folder when you change behaviour.
- Keep to Odoo 19 conventions: models in `models/`, views in `views/`, access rules in `security/`.
- Run the tests for the modules you touched before opening the pull request.

By submitting a contribution you agree that ICT Innovations may distribute it under the LGPL-3 and under the licences used for ICTERP Enterprise services. If that does not suit you, say so in the pull request before it is merged.

Report security problems privately through https://service.ictinnovations.com/submitticket.php rather than in a public issue.
