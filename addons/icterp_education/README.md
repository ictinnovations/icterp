# ICTERP Education

School, college and university management for ICTERP: students, admissions, timetable, attendance, exams, fees and library

- Technical name: `icterp_education`
- Version: 19.0.1.0.0
- Licence: LGPL-3
- Depends on: `icterp_branding`, `openeducat_erp`, `openeducat_timetable`, `openeducat_fees`, `openeducat_classroom`, `openeducat_facility`, `openeducat_activity`

## Needs

OpenEduCat Community 19.0 (LGPL-3). Run `tools/vendor-openeducat.sh addons-vendor/openeducat` and add that folder to the addons path. The script pins the upstream commit, swaps in ICTERP icons and disables OpenEduCat's usage reporting.
